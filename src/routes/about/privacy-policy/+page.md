**Effective date:** August 29, 2026

Commonway System doesn't run accounts, doesn't sell anything, and doesn't collect information directly from visitors beyond what's described below. This page covers the third-party services the site relies on, and the ordinary logging that comes from being hosted on the web at all.

## What we use

**Google Analytics.** We use Google Analytics to understand how the site is used: which pages get visited, how people arrive at the site, and general device and browser information. This is aggregate usage data, not information tied to your name or identity. See [Google's own privacy policy](https://policies.google.com/privacy) for how Google processes this data.

**GitHub.** The site's content and code are maintained in a public GitHub repository. If you open an issue, submit a pull request, or otherwise interact with the repository, GitHub collects and publicly displays your GitHub username and activity, the way it does for any public repository. We don't control that data ourselves; see [GitHub's Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement) for how GitHub handles it.

**Netlify (hosting).** This site is hosted as a static site through Netlify, which automatically logs basic request information (like IP address and request timestamp) as a normal part of serving any website. We don't use this data ourselves beyond what Netlify's own infrastructure requires to operate. See [Netlify's Privacy Policy](https://www.netlify.com/privacy/) for details.

We don't run ads, don't sell or share data with advertisers, and don't have any other analytics, tracking, or data collection on the site beyond what's listed above.

## Cookies

Google Analytics may set cookies in your browser to distinguish visitors and sessions. You can block or delete these through your browser's settings, or use [Google's Analytics Opt-out Browser Add-on](https://tools.google.com/dlpage/gaoptout) to opt out entirely. Blocking cookies won't affect your ability to read the site; it only affects the usage data we can see.

## Children's privacy

Commonway System isn't directed at children, and we don't knowingly collect personal information from anyone under 13.

## Links to other sites

Nearly every pattern page in the guide cites external sources: government manuals, published studies, agency documents. Clicking through to those sources takes you to a site we don't control and aren't responsible for. Check the privacy practices of any external site you visit from a citation link.

## Your choices

You can use the Google Analytics opt-out tool linked above, adjust your browser's cookie and tracking settings, or use browser extensions that block analytics scripts. None of this affects your ability to use the site.

## Changes to this policy

This page may be updated as the site's tools or practices change. Updates are reflected in the site's version history the same way any other content change is; see [Release History & Roadmap](/about/release-history/).
