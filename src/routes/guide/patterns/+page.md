Every Street Typology in the current Commonway System working set, grouped by Functional Classification. Scale hierarchy runs Network, Corridor, then Segment and Intersection as siblings, then Facility and Element; every entry below is Segment scale except the Intersections & Crossings group, which is Intersection scale.

## Collector

Speed rule: 30 mph standard, 35 mph permitted only with rigid crash-protective separation. Base modal hierarchy: Pedestrian, Bicycle, Transit, Vehicle, Freight.

- [Default (Standard Collector)](/guide/collectors/default/) — COL-DEF-01
- [Rural Collector / Farm-to-Market Road](/guide/collectors/rural-collector/) — COL-FTM-02
- [Industrial Collector](/guide/collectors/industrial-collector/) — COL-IND-03
- [Bike Highway / Greenway](/guide/collectors/bike-highway-greenway/) — COL-BHG-04

## Arterial

Speed rule: design speed always equals posted speed. Base modal hierarchy: Transit, Pedestrian, Bicycle, Vehicle, Freight. Core safety rule: never mixes on-street parking or direct property access with through traffic.

- [Default (No Parking, No Direct Access)](/guide/arterials/default/) — ART-DEF-01
- [Boulevard](/guide/arterials/boulevard/) — ART-BLV-02
- [Scenic Highway / Byway](/guide/arterials/scenic-highway-byway/) — ART-SCB-03
- [Arterial Transit (BRT/LRT)](/guide/arterials/arterial-transit/) — ART-ATR-04
- [Stroad](/guide/arterials/stroad/) — ART-STD-05 · **Avoid**
- [One-Way Street](/guide/arterials/one-way-street/) — ART-OWS-06 · Situational/Discouraged

## Intersections & Crossings

Cuts across all four Functional Classifications rather than nesting under one. Intersection philosophy: roundabout default wherever two Collector-or-higher streets meet, turbo-roundabout at high-volume Arterial-to-Arterial junctions, signal as a documented last resort, continuous sidewalk as the Local-to-Collector default.

- [Roundabout (Single/Multi-Lane)](/guide/intersections/roundabout/) — INT-RAB-01
- [Turbo-Roundabout](/guide/intersections/turbo-roundabout/) — INT-TRB-02
- [Signal](/guide/intersections/signal/) — INT-SIG-03
- [All-Way Stop](/guide/intersections/all-way-stop/) — INT-AWS-04
- [Stop / Yield (Two-Way)](/guide/intersections/stop-yield/) — INT-SYD-05
- [Continuous Sidewalk / Raised Junction](/guide/intersections/continuous-sidewalk/) — INT-CSJ-06
- [Uncontrolled](/guide/intersections/uncontrolled/) — INT-UNC-07
- [Midblock Pedestrian Crossing](/guide/intersections/midblock-crossing/) — INT-MPC-08
- [Driveway / Curb Cut](/guide/intersections/driveway-curb-cut/) — INT-DCC-09
- [Grade-Separated Interchange](/guide/intersections/grade-separated-interchange/) — INT-GSI-10

## Under review, no confirmed Functional Classification

These Typologies are documented in Commonway System working notes but are not yet placed in the grid above, so they have no pattern page yet.

- **Parkway** (Freeway, historically ambiguous between Arterial-scale and Freeway-scale meanings)
