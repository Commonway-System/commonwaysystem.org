## Speed and modal hierarchy

30 mph standard. 35 mph is permitted only with rigid crash-protective separation, a concrete barrier rather than delineator posts, following FHWA's own distinction between the two. Modal hierarchy follows the Collector base order: Pedestrian, then Bicycle, then Transit, then Vehicle, then Freight, the same shape as Local. The higher speed tier loosens the practical design treatment, crossing spacing and separation, without changing the rank order.

## Design notes

This entry is the standard against which every other Collector Typology is defined as an override, the same role Default plays within Local.
