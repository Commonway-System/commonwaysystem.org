Every pattern page in this guide carries two kinds of backup: numbered citations at the bottom of the page, which back specific claims, and this section, which holds the fuller technical detail sitting beneath a pattern's plain-language description.

## What lives here

A pattern page tells you what a Street Typology is and when to use it. This section holds the layer beneath that: exact dimensions, formulas, design criteria, and specification tables, the detail a reader needs when they're actually drawing or building something, not just deciding what to build.

This is different from a page's References list. References back a specific claim with a source. This section expands on the claim itself with the numbers and criteria a citation alone doesn't carry.

## How it's organized

Reference entries follow the same Pattern ID used throughout the guide. A pattern's expanded technical detail, where it exists, sits at the same ID under this section.

## Where this stands today

This section is new. It's being built out pattern by pattern, and most patterns don't have an entry here yet. Where no entry exists, the pattern page itself is still the complete, current guidance, this section only adds detail beyond what's already there.
